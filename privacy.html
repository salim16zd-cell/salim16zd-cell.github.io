Privacy Policy: Drama Shorts Uploader

Last updated: November 20, 2026

Who uses this app

Drama Shorts Uploader is a personal tool used only by the owner of the YouTube channel @mindpickingstories1 to publish videos to that channel. It isn't offered to the public.

What data it accesses

With the owner's permission, through Google's OAuth sign-in, the app uses the YouTube Data API to upload videos, set their titles, descriptions, privacy settings and AI-content disclosure, and add caption files. It doesn't read viewers' data, comments, subscribers or any other account's information.

How data is stored

The only data kept is the OAuth access token. It's stored as an encrypted secret in the owner's private automation environment and is never shared, sold or sent to any third party. No personal data about viewers is collected.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the contact options on the channel's About page.
